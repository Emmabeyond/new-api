## 概述

BigAI Pro 推出用户等级系统，根据累计充值金额自动升级等级，不同等级享受不同的折扣优惠和专属权益。

## 等级体系

| 等级 | 等级名称 | 累计充值要求 | 说明 |
|------|----------|--------------|------|
| Lv.1 | **Explorer** | 无要求 | 新用户默认等级 |
| Lv.2 | **Voyager** | $100.00 | 探索者 |
| Lv.3 | **Pioneer** | $1,000.00 | 先锋用户 |

> 💡 **提示**: 充值任意金额即会触发升级检查，满足条件自动升级

### 折扣计算示例

假设您是 **Voyager** 等级，使用默认分组调用 API：

```
原始费用: $10.00
等级折扣: *0.90
实际扣费: $10.00 × 0.90 = $9.00
```

## 专属权益

### 优惠倍率

- 不同等级享受不同渠道折扣
- 折扣可以叠加（优先级比等级限制高）
- 6 个分组可享受独立折扣

### 并发限制

- **当前状态**: 所有等级均无并发限制
- **保留权利**: 平台保留后期调整并发限制的权利

### 可用渠道

根据等级可访问不同渠道分组：

- `default` - 默认渠道
- `vip` - VIP 渠道
- `Azure` - Azure 渠道
- 以及更多专属渠道...

## 升级规则

### 自动升级

- 每次充值后系统自动检测累计金额
- 达到升级条件立即升级，无需手动操作
- 升级后折扣立即生效

### 等级保持

- 等级根据历史累计充值金额计算
- 不会因消费而降级
- 永久有效

## 常见问题

### Q: 折扣是怎么计算的？

A: 折扣直接作用于原始费用。例如 *0.90 表示原价的 90%，即打 9 折。

### Q: 为什么我的折扣没有生效？

A: 请确认：
1. 已达到相应等级的充值要求
2. 使用的是有折扣的渠道分组
3. 可在等级页面查看实际折扣

### Q: 并发限制是什么意思？

A: 并发限制指同一时间可以发起的 API 请求数量。目前所有等级均无并发限制。

### Q: 等级会降级吗？

A: 不会。等级根据累计充值金额计算，一旦升级永久有效。

### Q: 如何快速升级？

A: 充值任意金额累计达到升级要求即可自动升级：
- 累计充值 $100 → Voyager
- 累计充值 $1,000 → Pioneer
