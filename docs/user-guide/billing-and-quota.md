## 计费模式

BigAI Pro 采用 **按量计费** 模式，根据实际使用的 Token 数量收费。

### Token 是什么？

Token 是大语言模型处理文本的基本单位：

- 英文：约 1 个单词 ≈ 1-2 个 Token
- 中文：约 1 个汉字 ≈ 1-2 个 Token
- 代码：根据复杂度，1 行代码 ≈ 3-10 个 Token

### 计费公式

```
费用 = (输入 Token × 输入价格) + (输出 Token × 输出价格)
```

## 额度管理

### 账户额度

账户总额度 = 充值金额 + 赠送额度

### 查看余额

1. 登录控制台
2. 顶部导航栏显示当前余额
3. 或进入「钱包」页面查看详情

### 充值方式

| 方式 | 说明 |
|------|------|
| 支付宝 | 即时到账 |
| 微信支付 | 即时到账 |
| 银行转账 | 1-3 个工作日 |
| 兑换码 | 即时到账 |

### 额度预警

设置余额预警，避免服务中断：

1. 进入「设置」→「通知设置」
2. 开启「余额预警」
3. 设置预警阈值（如 $10）
4. 配置通知方式（邮件/短信）

## 令牌级别限制

为单个 API Key 设置独立额度：

```
令牌额度 = min(令牌限制, 账户余额)
```

### 设置方法

1. 进入「令牌管理」
2. 编辑目标令牌
3. 设置「额度限制」
4. 保存配置

### 使用场景

| 场景 | 建议设置 |
|------|----------|
| 开发测试 | $10 - $50 |
| 个人项目 | $50 - $200 |
| 生产服务 | 根据预算设置 |
| 共享令牌 | 严格限制 |

## 费用统计

### 实时统计

控制台提供实时费用统计：

- **今日消费**: 当天累计费用
- **本月消费**: 当月累计费用
- **历史消费**: 历史费用趋势图

### 详细账单

查看详细调用记录：

1. 进入「日志」页面
2. 筛选时间范围
3. 查看每次调用的：
   - 使用模型
   - Token 消耗
   - 费用金额
   - 调用时间

### 导出账单

支持导出 CSV 格式账单：

1. 进入「钱包」→「账单」
2. 选择时间范围
3. 点击「导出」

## 成本优化建议

### 1. 选择合适的模型

| 任务类型 | 推荐模型 | 原因 |
|----------|----------|------|
| 简单问答 | gpt-4o-mini | 性价比高 |
| 代码生成 | claude-3-5-sonnet | 代码能力强 |
| 复杂推理 | gpt-4o / o1 | 推理能力强 |
| 大量处理 | gemini-1.5-flash | 价格最低 |

### 2. 优化 Prompt

- 精简系统提示词
- 避免重复上下文
- 使用简洁的指令

### 3. 控制输出长度

```python
response = client.chat.completions.create(
    model="gpt-4o",
    messages=[...],
    max_tokens=500  # 限制输出长度
)
```

### 4. 使用缓存

对于重复查询，实现本地缓存减少 API 调用。

## 常见问题

### Q: 余额不足会怎样？

A: API 调用会返回 `402 Payment Required` 错误，服务暂停直到充值。

### Q: 如何获取发票？

A: 进入「钱包」→「发票」，填写开票信息申请。

### Q: 充值后多久到账？

A: 在线支付即时到账，银行转账 1-3 个工作日。

### Q: 可以退款吗？

A: 未使用的充值金额可申请退款，联系客服处理。
